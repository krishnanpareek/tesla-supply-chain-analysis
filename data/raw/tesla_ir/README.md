# data/raw/tesla_ir/

Untouched Tesla quarterly production / deliveries / deployments releases for **Q1 2022–Q2 2026**.

## What is stored here

SEC Form **8-K Exhibit 99.1** HTML filings that contain Tesla’s production/delivery press release for each quarter (Item 2.02). These are the filed versions of the IR releases.

Naming pattern:

`tesla_production_deliveries_<PERIOD>_<PUBLICATION_DATE>_<original_sec_filename>.htm`

## Provenance

See `data/reference/download_log.md` for Source_ID, publication date, reporting period, accession number, and source URL for every file.

Do not edit these files. Cleaning belongs in `data/processed/` / `sql/cleaning/`.
